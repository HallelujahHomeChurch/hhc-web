## Implementation

- My Notes keeps a fixed frame, title/X and category header. Its three Tabs are notes/highlights/bookmarks, centered over a sliding selection pill; active content alone scrolls. The normal sync footer reserves space so background status cannot move the title/Tabs. Search fields share geometry and stable scrollbar gutter; color filters and recolor controls are removed.
- Legacy annotation UI and its unused component are removed. Existing server data, mutation types and explicit recovery compatibility remain intact; opening the list sends no deletion or history mutation.
- Note rows use named, hover-labelled jump/edit/delete/reanchor icon buttons. Highlight rows retain their saved color only as a citation accent and use a right-hand X to clear the exact range.
- Editor uses the same fixed frame with a body that can shrink/scroll and a bottom action row. The viewport-bound phone frame moves above a reduced visual viewport. Initial notes loading stays within the panel and cannot present a false empty list; real load failure keeps retry.
- Exit confirmation uses the house dismissable Dialog. Backdrop, Escape, X and Continue reading cancel the request. Cancelling after confirmation invalidates its token; late progress work cannot navigate or discard a draft. Deletion/discard decisions retain their existing AlertDialog safety semantics.
