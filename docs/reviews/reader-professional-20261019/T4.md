# T4 — mobile clause selection

Scope: Chinese comma/period boundaries inside existing canonical sentences, with closing punctuation and Unicode scalar offsets retained. Canonical documents, sentence IDs and stored bookmark/note anchors are unchanged. Desktop native selection remains supported.

## Implementation

`text-clauses.ts` defines boundaries, validates mounted fragment attributes/text, and extends only adjacent units into one continuous passage. Tapping an existing unit clears the passage; a distant unit starts a new passage. More than 500 ranges is refused. The shared hook hit-tests actual Range rectangles, ignores moved/cancelled/multiple pointers and native pinch scale, and supports clause keyboard navigation. Page-arrow shortcuts leave role=button sentence controls alone.

Paper/ebook select the actual scalar range, painted in a separate overlay without changing text or paragraph geometry. Duplicate browser rectangles are removed. Copy, highlights, note creation, return-state and local mutations retain these exact ranges. Reanchor and Recovery render individually selectable clauses and announce the selected quote. Ordinary saving remains quiet and nonblocking under T1's persistence contract.

## Round 2 revision — clock boundary and keyboard parity

The original caught error was `offline_access_expired` in the private intent persistence path. A deterministic regression starts a binding refresh at time t, advances the clock 1ms, and queues a private read. The old refresh waits for one transaction, then compares its early timestamp t with the later read's persisted high-water mark t+1. It falsely rejects valid access. `/tmp/reader-t4-clock-before.json` records the unchanged assertion failing before the fix (0 PASS/1 FAIL).

Storage now accepts the existing explicit numeric test instant or a live clock, defaulting to `Date.now` without evaluating it at call entry. Access checks read the live clock after queued IDB reads; refresh/commit paths sample inside their transaction. Sync/recovery pass their injected clock through to storage instead of freezing an early number. No time is clamped to the high-water mark, and the seven-day ceiling, same-receipt deadline, epoch/account/instance/revision checks and actual rollback lock remain in place. The regression explicitly moves the live clock backwards after successful concurrency and still requires rejection.

Keyboard: Shift+Left/Right extends at the corresponding selected boundary; ordinary arrows/Home/End select a single target, Enter/Space cancel/toggle, and an end boundary does not accidentally clear selection. Localized aria help describes the extension gesture. The new regression covers multiple adjacent clauses, boundary no-op, clearing and distant reset.
