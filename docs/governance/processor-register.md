# Personal-Data Processor Register

Last engineering review: 2026-09-12. This register describes active platform integrations; it is not a contractual or legal approval record. `pending_external_review` means counsel or the business owner must verify the agreement, transfer mechanism, retention, or exact legal entity.

| Provider / capability | Data and purpose | Region / transfer | Engineering controls | External review |
| --- | --- | --- | --- | --- |
| Microsoft Azure — hosting, PostgreSQL, Blob, Redis, Service Bus, Key Vault, Container Registry | Account records, content, assets, delivery jobs, application telemetry, secrets; platform operation | Configured Azure deployment regions; support/processing transfer terms `pending_external_review` | Managed identities, private service calls, encryption, least privilege, release evidence, backup/restore controls | DPA, subprocessor list, regional settings, deletion/backup terms `pending_external_review` |
| Cloudflare Turnstile | Browser signals, IP/network and challenge result; registration and abuse prevention | Provider processing locations `pending_external_review` | Site key in browser, secret server-side, token verification, no Account password disclosure | Terms, retention, transfer and exact controller/processor role `pending_external_review` |
| Sentry | Sanitized frontend errors, traces, request/correlation metadata; reliability and security diagnosis | Project region and support access `pending_external_review` | Event/breadcrumb sanitizers, constrained ingest CSP, sampling, no secrets or raw auth payloads | DPA, retention, project region and subprocessor list `pending_external_review` |
| Google OAuth | Provider subject, email/profile claims, authentication metadata; sign-in and identity linking | Provider processing locations `pending_external_review` | OIDC state/nonce, server callback validation, minimum scopes, linked-identity controls | OAuth terms, retention, transfer and exact entity `pending_external_review` |
| Microsoft OAuth | Provider subject, email/profile claims, authentication metadata; sign-in and identity linking | Provider processing locations `pending_external_review` | OIDC state/nonce, server callback validation, minimum scopes, linked-identity controls | OAuth terms, retention, transfer and exact entity `pending_external_review` |
| LINE Login / Messaging API | LINE subject, display/profile claims and webhook metadata; sign-in, linking, and requested messaging workflows | Provider processing locations `pending_external_review` | Signature/state validation, scoped identity mapping, private webhook route, no provider token in browser | Terms, retention, transfer and exact entity `pending_external_review` |
| Azure Communication Services Email | Recipient address, locale, template variables, delivery metadata; transactional and authorized campaign email | Azure service region; downstream routing `pending_external_review` | Notification service owns durable delivery, suppression, retries, secret isolation and minimal templates | Email DPA, routing, retention and subprocessors `pending_external_review` |
| Browser Web Push services | Push endpoint, public encryption keys, locale, delivery metadata; user-enabled browser notifications | Endpoint vendor chosen by the browser; location varies | Explicit opt-in, VAPID, encrypted payload, revocation/unsubscribe, same-origin action URLs | Browser-vendor terms, endpoint retention and transfer `pending_external_review` |

Review this file when adding a provider, changing a data category/purpose/region, or changing public policy text. Do not enable a new provider until its row, controls, and public disclosure are accurate.
