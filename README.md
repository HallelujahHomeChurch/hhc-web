# HHC Frontend

HHC frontend monorepo for the public website, account console, and admin console.

## Applications

- `apps/web`: `www.alive.org.tw`
- `apps/account`: `account.alive.org.tw`
- `apps/admin`: `admin.alive.org.tw`

## Commands

```bash
pnpm install
pnpm dev:web
pnpm dev:account
pnpm dev:admin
pnpm test
pnpm lint
pnpm build
```
